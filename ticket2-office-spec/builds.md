### Build 1 — Accountant
**Load:** Heavy Excel files, 1C Accounting software, banking portals, and local document management.
**Bottleneck:** Fast storage I/O and single-core CPU performance for recalculating large spreadsheets.
**Trade-off:** Omitted a dedicated GPU entirely. Spent the savings on a highly reliable Samsung 980 Pro SSD and an Intel Core i5 processor to guarantee instant load times and snappy software response.
**Total:** 424,900 KZT

### Build 2 — Sales Manager
**Load:** CRM in a browser, 30–40 tabs, Excel, four hours of video calls a day, sometimes all at once.
**Bottleneck:** Memory, not CPU. Chrome with forty tabs plus a video call is around 11–12 GB. On 8 GB the machine starts swapping in the middle of a customer call.
**Trade-off:** Took a Ryzen 5 instead of a Ryzen 7 and spent the ~60,000 KZT saved on 32 GB instead of 16 GB. The CPU idles in this role; the memory does not.
**Total:** 428,900 KZT

### Build 3 — Web Developer
**Load:** Local server environments, Docker containers, large IDEs (WebStorm/VS Code), compiling code, and cross-browser testing.
**Bottleneck:** CPU multi-threading (running several containers simultaneously) and memory capacity.
**Trade-off:** Dropped the dedicated graphics card (using Intel integrated graphics) to fund an Intel Core i7-14700K (20 cores) and 64 GB of DDR5 memory. The machine will compile lightning-fast, but cannot render 3D graphics efficiently.
**Total:** 707,500 KZT

### Build 4 — Designer
**Load:** Adobe Premiere (4K timelines), Photoshop, Illustrator, Figma, often running simultaneously.
**Bottleneck:** GPU VRAM for video timelines/effects, GPU core speed for rendering, and monitor color accuracy.
**Trade-off:** Kept the SSD at the mandated 1 TB minimum to afford an RTX 4070 12GB GPU and an ASUS ProArt color-accurate monitor. Storage capacity was sacrificed to secure essential rendering performance and color accuracy within the company budget.
**Total:** 1,312,500 KZT
